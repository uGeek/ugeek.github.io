Tunel SSH para conectar puertos remotos como si fuera local

Lectura: 2 min. 207 palabras. ssh

En este proceso lo más importante, es tener en el directorio .ssh de tu usuario root, los archivos de configuración para acceder al servidor remoto. Piensa que para desviar los puertos remotos del servidor a nuestro PC, es necesario tener permisos de super usuario y la conexión se hará mediante el usuario root.

Un truquillo si el PC es tuyo y no quieres complicarte configurando nuevamente el servidor SSH, sería copiar el directorio .ssh de tu usuario al del usuario root.

En el archivo de configuración config dentro del directorio .ssh, he añadido la conexión a mi vps con el nombre vps.  

Ahora vamos a enlazar un puerto remoto de syncthing del vps con el puerto local, lo que se llama Reenvío de Puertos (Port Forwarding)

Para vincular el puerto remoto 8384 del VPS al puerto local 8385 en tu PC, ejecuta:

ssh vps -fNL 8385:localhost:8384


Desglose del comando:

-L especifica reenvío local (local_port:remote_host:remote_port)

El primer localhost se refiere al VPS (no a tu máquina local)

La opción -N evita ejecutar comandos remotos, útil solo para reenvío de puertos

-f envía SSH a segundo plano tras autenticarse

Otras Opciones 

-i /ruta/a/key especifica una clave particular si difiere de la predeterminada

-vvv muestra salida detallada para depuración
