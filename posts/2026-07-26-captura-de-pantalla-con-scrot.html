Captura de Pantalla con Scrot e i3wm

Lectura: 2 min. 390 palabras.

Introducción

Scrot es un programa que toma fotos de tu pantalla

Cuando usas una computadora, a veces quieres guardar lo que ves en la pantalla. Scrot es un programa muy rápido, pequeño y ligero que hace exactamente eso, capturar toda la pantalla, solo una ventana, o solo una parte que tú selecciones con el ratón. Ideal para integrar en tu escritorio.

Instalación

Arch Linux

Desde los repositorios oficiales. 

sudo pacman -S scrot xclip

Nota: Se instala también xclip porque es la herramienta que permitirá copiar la captura directamente al portapapeles en lugar de (o además de) guardarla como archivo.

En Debian (y derivados como Ubuntu, Mint)

En Debian, scrot se encuentra en los repositorios main:

sudo apt update && sudo apt install scrot xclip

Esto instalará tanto scrot como xclip desde los repositorios estables de la distribución.

Comandos básicos de Scrot

Antes de pasar a la configuración de i3wm, conviene conocer los comandos más útiles:

Comando Descripción
scrot Captura toda la pantalla y la guarda en el directorio actual
scrot -d 5 Captura tras un retardo de 5 segundos
scrot -s Permite seleccionar una región o ventana con el ratón
scrot -u Captura la ventana actualmente enfocada
scrot -s - Envía la captura de la región seleccionada a stdout (para pipes)
scrot '%Y-%m-%d_$wx$h.png' -e 'mv $f ~/Imágenes/' Guarda con nombre con timestamp y mueve a una carpeta

El flag -s combinado con - (guión) es particularmente interesante: envía la imagen capturada a la salida estándar en lugar de escribirla a disco, lo que permite encadenarla con otros comandos.

Integración con i3wm

i3wm permite definir atajos de teclado (keybindings) mediante la directiva bindsym en su archivo de configuración. El archivo de configuración se encuentra típicamente en ~/.config/i3/config

Atajo básico: captura de región al portapapeles

# CAPTURA DE PANTALLA bindsym Print exec scrot -s - | xclip -selection clipboard -t image/png

Atajo básico: captura de región al portapapeles y guardalo en una archivo en ~/Imágenes/Capturas/

# Captura de región seleccionada → archivo guardado
bindsym $mod+Print exec scrot -s '%Y-%m-%d_%H%M%S_scrot.png' -e 'mv $f ~/Imágenes/Capturas/'

Otras opciones

Pantalla Completa

# Captura de pantalla completa → portapapelesbindsym $mod+Print exec scrot - | xclip -selection clipboard -t image/png

Captura de Ventana

# Captura de ventana activa → portapapelesbindsym $mod+Shift+Print exec scrot -u - | xclip -selection clipboard -t image/png
