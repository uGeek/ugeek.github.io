TigerVNC Arranque automático al incio (2026)

Lectura: 1 min. 140 palabras. vnc

Si necesitas que tu servidor TigerVNC se inicie automáticamente al arrancar el sistema o al iniciar sesión, puedes configurarlo como un servicio de usuario en Systemd. A diferencia de los servicios del sistema (que requieren sudo), este método ejecuta el servidor VNC bajo tu usuario, con los permisos adecuados para acceder a tus archivos y recursos.

Crea el archivo de servicio

Crea la carpeta donde se guardan los servicios de usuario y abre el editor para crear el archivo de configuración del servicio VNC.

mkdir -p ~/.config/systemd/user/ ; nano ~/.config/systemd/user/vncserver.service

Pega este contenido, si el usuario es :1

[Unit]
Description=Servidor VNC
After=network.target

[Service]
Type=simple
# Limpieza previa
ExecStartPre=/bin/sh -c '/usr/bin/vncserver -kill :1 > /dev/null 2>&1 || true'
# Ejecución con la sintaxis corregida
ExecStart=/usr/bin/vncserver :1
Restart=on-failure
RestartSec=5

[Install]
WantedBy=default.target

Habilita el servicio

systemctl --user daemon-reload ; systemctl --user enable vncserver.service
